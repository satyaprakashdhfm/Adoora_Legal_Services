# Static assets

| File | What it is |
| --- | --- |
| `adoora-mark.png` | The firm's triangular "A" mark, flattened to a single gold (`#C88A4E`) silhouette on a transparent ground. Generated from `resources/als logo A.png`; the cut-outs deliberately show whatever sits behind them, exactly as the letterhead uses it. |
| `hero-law-justice.png` | Supplied by the firm. The home-page hero photograph — the scales of justice on the law/justice volumes. The composition keeps its subject on the right, because the navy wash covers the left half where the headline sits. Any replacement should hold that framing. |

The app icons live at `src/app/icon.png` and `src/app/apple-icon.png` — Next.js
picks those up from the `app` directory, not from here.
